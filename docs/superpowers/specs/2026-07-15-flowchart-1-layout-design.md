# 流程圖 1 中度重排設計

## 目標

改善 Page13 `#fbox1` 的節點、標籤與路徑間距，使主流程、判斷分支與回流關係更容易閱讀。

## 範圍

- 只修改作用中的 `buildDio('fbox1', ...)` 節點幾何與 edge route。
- 保留全部節點文字、泳道角色、流程邏輯、Y/N 意義及接點編號。
- 不修改 `fbox2`、`fbox3`、舊版 `FLOWS` 或 `buildDrawio1`。

## 版面設計

1. 將「開始／查看生產排程 → 是否接單 → 是／否 → 客戶區分」整理成間距一致的上方決策區。
2. 「是／否／結束」在同一列對齊；「新客戶／舊客戶」採對稱排列。
3. 兩個「提供檔案」維持客戶欄與設計欄，並以一致列距呈現。
4. 「接洽報價 → 正式報價 → 客戶確認」形成清楚的主流程帶；跨泳道線採水平與垂直正交轉折。
5. 「對報價不滿 → 接洽報價」沿客戶／業務泳道邊緣回流，避開主流程節點。
6. 「舊客戶提供檔案 → 溝通與整理檔案」沿設計欄側邊導軌下行，避免穿過節點。
7. Y/N 標籤使用緊湊樣式，置於節點外的線段空白處。

## 驗收條件

- `fbox1` 維持 18 個節點與 19 條 edge，所有 edge endpoint 有效。
- 節點彼此不重疊；edge 不穿過非端點節點；標籤不遮住節點或箭頭。
- 方向與流程語意不變，接點 `1` 仍位於設計欄。
- `fbox2`、`fbox3` 的來源定義完全不變。
- 來源驗證、單元測試及瀏覽器 console 無錯誤。
- 在 1920x1080、1280x720、768x1024、375x667、667x375 下完整顯示。
