# Page13-15 流程圖互動動畫設計

## 目標

為 Page13、Page14、Page15 的作用中 `buildDio` 泳道流程圖加入全畫面逐步播放、當前節點呼吸發光、已走訪節點深藍標示，以及固定的 N 優先分支回流邏輯。

## 範圍

- 套用於 Page13 `#fbox1`、Page14 `#fbox2`、Page15 `#fbox3`。
- 不修改任何節點文字、泳道、位置、尺寸、形狀、顏色定義、edge endpoint、線路或 Y/N 標籤。
- 不啟用或修改舊版 `FLOWS`、`buildDrawio1` 與舊版播放按鈕。
- 保留既有翻頁、頁碼與響應式縮放行為。

## 視覺狀態

### 初始狀態

- 所有節點維持目前由 `blue`、`red`、`white`、`dec`、`conn` 等 class 決定的原始底色。
- 頁面載入時不預先啟用任何節點；第一次左鍵點擊才啟用流程起點。

### 當前節點

- 當前節點保留原始底色。
- `.shape` 使用亮橘色外框與橘色 drop-shadow。
- 套用約 1.1 秒循環的 Pulse 呼吸動畫，僅改變發光強度與外框視覺，不改變節點尺寸或位置。
- 當系統偏好 `prefers-reduced-motion: reduce` 時停止呼吸動畫，但保留橘色發光外框。

### 已走訪節點

- 當流程前進時，上一個當前節點移除橘色發光與 Pulse。
- 節點底色改為深藍色，文字改為白色。
- 當流程自動或手動回到已走訪的判斷點時，該點暫時移除已走訪樣式、恢復原底色並重新顯示橘色 Pulse；再次離開後再回到深藍狀態。

## 互動機制

- 只監聽滑鼠左鍵；右鍵與其他按鍵不觸發流程。
- Page13-15 任一頁為作用中頁面時，使用者在畫面任意位置按一下左鍵，就將該頁流程前進一個節點。
- 使用 capture 階段處理全域點擊，使翻頁控制仍正常執行，且該次點擊先推進點擊當下的作用中流程，再執行翻頁。
- 三張流程圖各自保存獨立進度；切換頁面後再返回時保留原進度。
- 自動回跳期間鎖定該流程，避免快速連點跳過判斷點。
- 流程完整結束後保留最後節點為當前狀態；再點一次會清除該頁所有狀態並重新啟用起點。

## 播放控制器

### 節點識別

- `buildDio` 建立每個 `.dio` group 時加入 `data-node-id`，讓控制器只透過穩定 node id 切換 class。
- 不改變 SVG 節點順序或 edge 渲染順序。

### 路徑表格式

- 每張流程圖使用明確播放路徑表，而非執行時推測 graph。
- 一般項目為 node id，每次點擊前進一項。
- 自動回跳由目前項目附帶 `autoReturn` 目標表示；終點先顯示約 700ms，再自動回到指定判斷點。
- 路徑表只控制動畫狀態，不新增或改寫任何 SVG edge。

## Page13 路徑

### 新客戶路徑

1. `st` 開始
2. `n1` 查看生產排程
3. `n2` 是否接單
4. `no` 否
5. `end1` 結束，700ms 後自動回 `n2`
6. `yes` 是
7. `n3` 客戶區分
8. `nc` 新客戶
9. `f1` 提供檔案
10. `n5` 接洽報價
11. `n6` 正式報價
12. `n7` 客戶確認
13. `n7n` 對報價不滿
14. `end2` 結束，700ms 後自動回 `n7`
15. `n7n` 對報價不滿
16. `n5` 接洽報價
17. `n6` 正式報價
18. `n7` 客戶確認
19. `n8` 溝通與整理檔案
20. `c2` 接點 1，700ms 後自動回 `n3`

此順序實現「客戶確認」特殊規則：先不滿意至結束，再回報價流程，最後才走 Y。

### 舊客戶路徑

1. `oc` 舊客戶
2. `f2` 提供檔案
3. `n8` 溝通與整理檔案
4. `c2` 接點 1

舊客戶路徑結束後，下一次點擊重設 Page13 並從 `st` 重新開始。

4. `w3` 現場定位與安裝
5. `w4` 客戶驗收
6. `c1b` 接點 1，700ms 後自動回 `w4`

客戶驗收第一次走 N 至接點 1，自動返回後再走 Y 至通知請款。

## 測試與驗收

### 來源測試

- 三張流程圖每個 `.dio` group 均包含正確 `data-node-id`。
- 路徑表與上述順序完全一致。
- 自動回跳點與目標完全一致。
- CSS 同時包含初始、當前、已走訪與 reduced-motion 狀態。
- 全域左鍵 handler 只推進作用中 Page13-15 的對應流程。
- 既有 18/19、11/12、11/10 node/edge 契約與全部節點、endpoint 不變。

### 瀏覽器行為

- 第一次點擊只啟用起點。
- 每次點擊只前進一個節點；上一節點立即轉深藍。
- 自動回跳前，N 終點至少顯示一次橘色 Pulse。
- 自動回跳期間連點不會跳步。
- Page13 完整順序為新客戶後舊客戶，且「客戶確認」依指定三階段順序執行。
- Page14、Page15 的 N 分支先於 Y 分支。
- 翻頁後各頁進度獨立保留。
- 流程完成後下一次點擊可重新開始。

### 視覺與回歸

- Page13、Page14、Page15 在 `1920x1080`、`1280x720`、`768x1024`、`375x667`、`667x375` 完整顯示。
- Pulse、Glow 與深藍已走訪樣式不改變節點尺寸，不造成文字、節點、線路、頁碼或翻頁控制重疊。
- JavaScript runtime 無例外；現有 Node 與 Python 測試全部通過。
